# Player Manager
Это небольшая консольная программа написанная мной для изучения языка программирования **Python**. Чтобы запустить её понадобиться **Python 3.14** и выше. Для начала работы запустите файл **main.py**. В идеале вы должны увидеть в консоли приветственное сообщение со списком доступных команд.
```
Добро пожаловать в менеджер игроков!
    Вот список доступных команд:
    /help - выводит список команд
    /add - добавляет игрока
    /delete - удалить игрока
    /search - найти игрока (проверить есть ли такой игрок)
    /show - вывести всех игроков
    /exit - выход из программы
```
После закрытия программы все созданные и когда-то добавленные игроки, сохранятся в файл save_players.json в папке Saves.
Данный файл имеет такую структуру:
```json
{
    "players": {
        "имя игрока":{
            "name": "имя игрока",
            "level": 1,
            "points": 0
        }
    }
}
```
Вы можете сами в ручную добавлять сюда игроков или редактировать их.
